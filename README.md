# A OOP Project in Python

## Description

This project is a simple coffee shop simulation using Object-Oriented Programming (OOP) in Python.

## Features

- Clientes
- Workes
- Coffes
- Pays

## Installation

1. Clone the repository
2. Create a virtual environment
3. Activate the virtual environment
4. Install dependencies
5. Run the application

## Usage

```bash
py main.py
```
